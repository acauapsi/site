ESCLARECIMENTOS

Dúvidas Frequentes

O Acauã App atende às exigências da LGPD e do CFP? +

Sim. O sistema utiliza banco de dados SQLite criptografado com SQLCipher (AES-256). Os prontuários ficam armazenados exclusivamente no seu notebook com Senha Mestra, garantindo a guarda sigilosa exigida pela Resolução CFP nº 01/2009 e LGPD.

O pagamento é realmente único ou tem mensalidade? +

O pagamento é 100% ÚNICO! Você adquire a licença do software ou a criação do site e eles são seus para sempre, sem mensalidades recorrentes.

Como funciona o Combo Panelinha para turmas? +

Você junta 2, 4 ou 6 amigos da sala ou estágio. Ao fazerem o pedido juntos, cada um recebe sua licença/site próprio de forma independente, aproveitando o desconto coletivo de turma!

De quem é a responsabilidade dos dados? +

100% sua. O Acauã App é um software offline e local — os dados ficam salvos exclusivamente no seu computador, criptografados. Nenhum dado é enviado para servidores externos ou terceiros. Você é o único guardião das informações dos seus pacientes.

E se eu formatar o computador ou trocar de PC? +

Sem problema. Basta fazer um backup do arquivo do banco de dados antes de formatar (processo simples documentado). Ao reinstalar o Acauã App no novo PC, você importa o arquivo e todos os prontuários estarão lá, intactos.

Sou estudante — posso usar sem ter o CRP? +

Sim! O Acauã App é uma ferramenta de organização pessoal — você pode usá-lo durante o estágio supervisionado para organizar seus atendimentos. A licença é sua e não expira, então quando vier o CRP você já estará com tudo estruturado.

E sobre domínio e hospedagem do site? +

O site é hospedado gratuitamente e de forma vitalícia via GitHub Pages — sem mensalidade, sem custo recorrente. Para o domínio personalizado (ex: dra.seunome.com.br), o único custo é o registro anual do domínio (~R$ 40/ano), feito diretamente por você no Registro.br. Isso é opcional; o site funciona normalmente sem domínio próprio.
